# История Беларуси · ЦТ — Flutter-приложение (v2)

Что внутри: учёба по разделам, тесты (даты и термины), XP, уровни, серия дней,
достижения, повторение ошибок, таймер фокуса, ежедневные напоминания, статистика.

## Как получить APK
1. Загрузи все файлы этой папки в репозиторий на GitHub.
2. Убедись, что файл `.github/workflows/build-apk.yml` содержит НОВЫЙ текст
   (копия лежит в `build-apk.yml` в корне архива).
3. Вкладка **Actions** → **Build APK** → дождись зелёной галочки (5–10 минут).
4. Внизу страницы запуска → **Artifacts → CTHistory-apk** → скачай и распакуй → `app-release.apk`.

## Структура
- `lib/` — код приложения; `assets/sections.json` — все темы, даты, термины
- `android_overrides/`, `tools/patch_android.py` — иконки, разрешения, подпись (применяются при сборке)
- `keystore/release.jks` — ключ подписи: благодаря ему новые версии ставятся поверх старых без потери прогресса.
  Не публикуй репозиторий и не удаляй этот файл.
